### Reproducibility of Additional Experiments

The scripts for the additional experiments are provided as follows:

- **Ablation analysis:** `ablations.py` and `run_ablation.py`.
- **Computational efficiency and scalability:** `scalability.py` and `run_scalability.py`.
- **Sensitivity and robustness analyses:** These experiments can be reproduced using the existing `DLPFC.ipynb` notebook by adjusting the corresponding parameter settings.
